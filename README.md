# 荒骸猎纪 DEV-001

Godot 4.7.2 + GDScript + Compatibility。独立横版训练战斗工程，非正式完整游戏。

**玩法**：移动、跳跃与缓冲、三段轻击、重击、闪避无敌窗口、体力与生命、训练兽 AI、攻击判定、手机多点触控。

**键盘**：A/D 或方向键移动，空格跳，J 轻击，U 重击，K 闪避，R 重开，F 全屏。手机端使用屏幕按钮。

**美术**：场景和角色目前仅使用明确标记的开发调试形状（DEBUG），并非暗黑像素正式素材，不算美术验收完成。不得使用概念图裁切冒充正式资源。

**网页**：https://zbeiqi485-maker.github.io/huang-hai-lie-ji/ （须以 GitHub Actions 构建及 Pages 实际可访问为准）

**验收**：CI 导出成功不代表 Android 多点触控、帧率及手感已经实机通过；未提供实机证据不得声称最终验收通过。
